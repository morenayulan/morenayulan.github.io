# PsiCrim — Portfolio de Morena

Portfolio web personal desarrollado para la materia **Aplicaciones Informáticas II (6° E)** - Instituto San Agustín.

## Estructura del proyecto
- `index.html`: Estructura semántica principal con diseño conversacional e interactivo en HTML5 puro.
- `css/estilos.css`: Hoja de estilos editorial, monocromática y de alto contraste (inspirada en el estilo de John Henry Müller).
- `bitacora_ia.md`: Registro de consultas y decisiones tomadas durante el desarrollo con asistencia de IA.
- `assets/img/`: Carpeta destinada a imágenes, logo y capturas de proyectos.
